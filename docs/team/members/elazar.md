  investigate, implement, test, document, integrate, and push approved scope

  Elazar can run locally.
- Ask only when a stop condition in `docs/coordination/AUTHORITY.md` or
  `docs/coordination/PRODUCTION_POLICY.md` applies.

## Boundaries

- Product, tax, accounting, security, schema, and production decisions remain
  subject to the shared authority policy.
- No credentials or private personal information belong in this file.
