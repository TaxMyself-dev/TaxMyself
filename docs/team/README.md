# Team profiles

This directory stores shared, non-secret information needed for managers to
coordinate people consistently. It is not a credentials store and does not
override repository-wide authority or production policy.

## Usage

- Each developer has one file under `members/`, created from `TEMPLATE.md`.
- A developer identifies their profile when opening a new manager chat.
- The manager reads the profile after root `AGENTS.md` and before accepting work.
- Repository-wide rules always win over an individual preference.
- Personal cross-project Codex preferences belong in the developer's local
  Codex home, not in this repository.
