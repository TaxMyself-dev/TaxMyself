# Categories and accounting redesign

This directory contains the binding plan, production-cutover material, review
evidence, and historical worklog for the in-progress accounting redesign.

## Authority order

1. Root `AGENTS.md` and `docs/coordination/PRODUCTION_POLICY.md` define safety
   and approval boundaries.
2. `categories-redesign-master-plan.md` is the source of truth for accounting
   design decisions D1-D15 and phase scope.
3. `cutover-day-checklist.md` and `cutover.sql` govern the approved cutover.
4. Review and audit files are evidence for specific phases; they do not override
   the master plan.
5. `worklog.md` is historical evidence, not an instruction source.

Do not delete or consolidate phase evidence while cutover is still in progress.
