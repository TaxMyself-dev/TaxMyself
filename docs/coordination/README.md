# Development governance

This directory contains repository-wide rules. Keep these files concise and
change them only in a dedicated documentation-governance task.

## Reading order

1. Root `AGENTS.md`.
2. `WORKFLOW.md` for the delivery lifecycle.
3. `AUTHORITY.md` for approval boundaries.
4. `QUALITY_GATES.md` before declaring a task verified.
5. `PRODUCTION_POLICY.md` for schema, credentials, deployment, or live systems.
6. `LESSONS.md` for known failure patterns.
7. `MANAGER_STATE.md` for the current integration handoff.

Task state lives under `../tasks/`, not in this directory.
