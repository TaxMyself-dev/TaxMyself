## Cause

KT-025 explicitly required `DOCUMENTS_WRITE`. Production contains valid
view-only delegations created by the owner permission flow with
`DOCUMENTS_READ` plus `EXPENSES_APPROVE`, so the guard rejected the PATCH even
though the accountant-client relationship was ACTIVE. The business-maintenance
capability is tied to the active relationship, not document-write permission.
