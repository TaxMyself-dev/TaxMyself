## Business outcome

When a zero-traffic Cloud Run candidate fails during startup, the operator sees
the application error that caused the failure instead of only `gcloud` exit
code 1.

## Acceptance criteria

- [x] Stage 8 queries only ERROR logs for the exact failed revision.
- [x] The terminal failure contains one concise application-error line.
- [x] Generic startup-probe messages do not hide a more useful application
      exception.
- [x] Diagnostic output is single-line, length-limited, and redacts common
      credential fields; raw logging JSON is not printed or persisted.
- [x] Failure to read Cloud logs preserves the original deployment error.
- [x] Release regression tests and PowerShell parsing pass.
