## KT-085 SHAAM allocation state machine (2026-10-21)

- Status: PUSHED
- Delivery: `27b28afe`
- Integration branch: `codex/integration-kt085`

Replaced supplier-side confirmation recovery with a fail-closed durable
Approval state machine. Each provider submission is recorded before the call
with an opaque request ID, exact-payload hash and lease. Live `PROCESSING` and
ambiguous `UNKNOWN_OUTCOME` states block automatic replay; successful
allocation persistence is atomic with the terminal attempt state and precedes
local PDF/journal finalization. Explicit rejection, validation/client failures
and ambiguous transport/server/malformed outcomes remain distinct.

Admins have guarded, audited resolution for externally confirmed
non-acceptance or an externally verified allocation. Normal users receive a
sanitized status and cannot resend or finalize without an allocation while the
outcome is unresolved. Structured logs exclude tokens, bodies, VAT/business/
customer numbers, document references, allocation numbers, dates and amounts.
